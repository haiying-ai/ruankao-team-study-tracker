## 学习口径

- 卡片是按附件范围整理的核心记忆点，不是把 529 页逐段搬入应用；不承诺覆盖每道例题、完整法规条文和每个过程的全部 ITTO。
- “全量模式”指所选模块的全部卡片；选择“全部知识”时覆盖当前 234 张，选择“49过程背图”时覆盖新增 15 张，用于考前自测，不代表教材所有原文。需要完整案例演算时仍结合讲义练习。
- 日期、法规和标准等内容以提供的课程版本为背景；本批次未额外把法规条文扩充成法律咨询内容。
- 答案采用归纳表达，意思正确即可判对，不要求逐字复述；有前提的公式须同时记住适用条件。
- EAC/ETC 区分剩余工作按原预算、按当前成本绩效、按成本与进度双绩效、重新估算四种假设。
- 正反推与自由时差的简式明确以 FS、零滞后为前提；其他关系或滞后需另计。
- 总浮动时间保护项目完工时间，自由浮动时间保护紧后活动最早开始；资源平衡可能改变关键路径和工期，资源平滑保持原完工日期。
- 个别练习型卡片基于讲义例题重新组织提问或简化数值；它们是知识回忆辅助，不是声称新增了一套官方真题。

## 维护与验证

`id` 为稳定标识，复习记录依赖它；调整字句保留原 ID，拆分或更换知识点时使用新 ID。卡片包含 `category`、`prompt`、`answer`、可选 `explanation`、`tags` 和 `sources`。

本次提取文本、生成脚本和中间卡片仅存放于 `.flashcard-work/`，正式运行无需读取它们。维护者可在本地保留原始材料后重新生成；不要把附件全文或个人本地路径作为浏览器可访问的资源发布。

内容验收：ID 唯一、必需字段非空、五种分类合法、所有出处页码在对应 PDF 范围内；49 个过程完整且过程组数量为 2/24/10/12/1；背图题数量为 5+10，两种方向分别无重复、无遗漏覆盖 49 个过程。已人工核对关键易混点：PV/EV/AC、EAC 假设、TCPI 的 BAC/EAC 目标、总/自由浮动时间、赶工/快速跟进、资源平衡/平滑、控制质量/确认范围与核实/验收/移交的区别。
